Qué es HALCON

Una plataforma de rastreo pensada para operaciones reales

No es un servicio genérico de mapas. Es un sistema que conecta hardware GPS con dashboards en vivo, con roles, permisos y persistencia. Cada pieza existe por una razón operativa.

Tiempo real, de verdad

Las coordenadas viajan por WebSocket, no por polling. La latencia entre que el GPS envía y el mapa actualiza es de milisegundos, no de segundos.

Aislamiento por usuario

Cada dashboard ve únicamente los halcones que le fueron asignados. Ni más ni menos. El servidor filtra en el WebSocket, no en el cliente.

Roles con responsabilidades

Admin gestiona todo. Moderador crea y asigna halcones. Usuario solo monitorea. Tres roles, responsabilidades claras, sin ambigüedad.

Capacidades

Todo lo necesario para operar sin sorpresas

Cada funcionalidad resuelve un problema concreto. No hay features decorativas.

Posiciones en vivo

Cada halcón emite coordenadas que se reenvían a los dashboards del dueño. Sin caché intermedia, sin polling, sin retrasos.

Mapa interactivo

Leaflet con tiles de OpenStreetMap. Sin API keys, sin cuentas de terceros, sin costos ocultos. El mapa es tuyo.

Rastro persistente

La trayectoria de cada halcón se acumula, se pinta como polilínea y se guarda localmente. Al reabrir la sesión, el rastro sigue ahí.

Multi-usuario con permisos

Un usuario puede tener varios halcones. Un halcón solo pertenece a un usuario a la vez. El historial de asignaciones se conserva.

Simulador integrado

Antes de conectar hardware, puedes simular coordenadas desde el panel de moderador. Útil para probar sin depender del GPS físico.

Buffer offline

Si la red cae, las posiciones se acumulan en el cliente y se sincronizan cuando vuelve la conexión. Nada se pierde.

Cómo funciona

Tres pasos para tener tu primer halcón en el mapa

No hay curva de aprendizaje. Si sabes usar un dashboard, ya sabes usar HALCON.

01

Se crea el halcón

Un admin o moderador registra el dispositivo. El sistema genera un token único que servirá para autenticarlo en el WebSocket.

02

Se asigna a un usuario

El halcón se vincula a un usuario y opcionalmente a un paquete. Desde ese momento aparece en su dashboard automáticamente.

03

El GPS empieza a emitir

El dispositivo se conecta al servidor con su token. Cada coordenada que envía viaja por WebSocket y llega al dashboard del dueño en tiempo real.

wss://tu-dominio/halcon/5/12/?token=a1b2c3… 5 es el ID del usuario dueño · 12 es el ID del halcón · el token lo genera HALCON al crear el dispositivo.
Casos de uso

Para operaciones donde la posición importa

HALCON no es para rastrear autos personales. Es para operaciones que necesitan trazabilidad, control por usuario, y datos que no se pierden.

Logística

Seguimiento de envíos

Cada paquete lleva su propio halcón. El cliente final ve exactamente dónde está su pedido, sin acceder a los demás.

  • Un halcón por paquete
  • Historial de recorrido completo
  • Rastro persistente entre sesiones
Flotas

Monitoreo de vehículos

Los operadores ven la posición de cada unidad en tiempo real, sin depender de apps propietarias ni de integraciones externas.

  • Dashboard por usuario
  • Aislamiento entre operadores
  • Control desde navegador, sin instalar nada
Operaciones

Activos distribuidos

Equipos de campo, contenedores, unidades móviles. Cualquier activo con GPS se convierte en un punto vivo en tu mapa.

  • Simulador para pruebas
  • Roles diferenciados
  • Buffer offline incluido
